Privacy

Y-Chat is a chat you run yourself. It is not affiliated with Yahoo.

A guest nickname is saved in this browser so the sign-in box can be filled in next time. Room messages and private messages are not saved on the server. Refreshing the page clears the messages and returns you to the same room and private chats. A short disconnect keeps the messages in this tab only.

An optional account stores a buddy list and a status message on the computer that runs Y-Chat. The password is stored as a hash, not as plain text.

Advertising is not turned on. If it is added later, it will be Google AdSense. Those ads are labeled Advertisement, sit on the welcome page and the room list, and do not appear inside a conversation. AdSense uses cookies to show and measure ads. Ads do not load until you accept.

Google Analytics loads only after you accept, and only when a measurement ID is set. Google then receives the page address and ordinary browser details. Nicknames, room names, and messages are not sent. With no measurement ID, that tag is not loaded.

The first time you open Y-Chat in a browser, we ask you to accept the Terms & Conditions and this policy. That choice stays in this browser so we do not ask again. Clearing site data brings the question back. If these pages change in a way that needs a new answer, we ask again.
